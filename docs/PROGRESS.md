### Not verified / limitations

- **No Android build in this environment.** The Android SDK download host (dl.google.com) is blocked here, so `flutter build apk` couldn't run locally. CI builds the release APK on GitHub's runners; check the first CI run. **Not run on a device or emulator yet**, so haptics, wakelock and real font rendering are untested on hardware (see `docs/qa-checklist.md`).
- **Flutter widget tests use the test font**, so they verify behaviour and layout rules, not visual polish. The website was checked visually via screenshots; the app was not.
- **Nothing deployed**; no store listing, domain or accounts exist.
- **Placeholder brand** (geometric mark), and legal pages are unreviewed drafts.
- **No analytics or crash reporting** (by design until Phase 5).
